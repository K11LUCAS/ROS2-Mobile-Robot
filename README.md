# ROS2 Mobile Robot

本项目计划基于 ROS2 构建移动机器人系统，内容包括机器人建模、运动控制、里程计发布、SLAM 建图和 Nav2 导航。

## Project Goals

- ROS2 topic / service / action 通信
- URDF 机器人建模
- TF 坐标变换
- /cmd_vel 速度控制
- /odom 里程计发布
- SLAM Toolbox 建图
- Nav2 自主导航

## Tech Stack

- ROS2
- Ubuntu
- C++ / Python
- SLAM Toolbox
- Nav2
- RViz
- Gazebo
